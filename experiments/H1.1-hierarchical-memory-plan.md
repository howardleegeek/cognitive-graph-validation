# Sub-Hypothesis H1.1: Hierarchical Memory for Long-Horizon Grounding

## Context
Previous experiments (H1.470.1.1.48) showed that the CognitiveGraph (CG) advantage over SimpleGRU collapses at sequence lengths $\ge 30$. While CG still maintains a lower validation loss (1.35x-1.39x), the underfit ratio drops from $\sim 10\text{x}$ to $\sim 1\text{x}$. This suggests that while the structural prior helps with average prediction, it doesn't solve the long-term dependency problem that causes underfitting in both architectures.

## Hypothesis
Integrating a Hierarchical Memory (HM) mechanism—where a slow-updating "context" node summarizes long-term state while the CG handles fast-updating physical dynamics—will restore the underfit ratio advantage at $\text{seq\_len} \ge 30$.

## Concrete Predictions
1. **Underfit Ratio**: At $\text{seq\_len}=30$ and $50$, the HM-CG model will maintain an underfit ratio $\ge 3\text{x}$ over the SimpleGRU, compared to the current $1.0\text{x}-1.9\text{x}$.
2. **Loss Stability**: The validation loss ratio (HM-CG vs GRU) will increase from $1.35\text{x}$ to $\ge 1.6\text{x}$, indicating better overall generalization.
3. **Failure Mode**: If the underfit ratio remains $< 2\text{x}$, the hypothesis is REFUTED, suggesting that the bottleneck is not memory capacity but rather the signal-to-noise ratio in the synthetic data or the lack of a temporal prior.

## Test Plan
1. **Architecture**: Implement `HierarchicalCognitiveGraph` which adds a slow-updating memory cell that integrates state over $k=5$ timesteps.
2. **Dataset**: Use existing `libero_synthetic_500.pkl` (or generate new data with $\text{seq\_len}=30, 50$).
3. **Baseline**: Compare against `SimpleGRU` and the standard `CognitiveGraph`.
4. **Metric**: Measure Underfit Rate (percentage of samples where error $> 2\times$ median error) and Validation Loss.
