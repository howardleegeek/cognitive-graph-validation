# H1.470: Error Accumulation in Unified Representations

## Hypothesis

CG's advantage decreases with task complexity because errors in the unified 
representation space accumulate across steps. In single-step tasks, the 
cross-modal grounding provides a clear signal. In multi-step tasks, small 
errors in the unified space compound, degrading the advantage.

## Concrete Prediction

If error accumulation is the mechanism, then:
1. CG's per-step error rate should be higher than baseline on multi-step tasks
2. Adding explicit error correction (residual connections) should disproportionately 
   help CG on multi-step tasks vs single-step tasks
3. The performance gap should scale with the number of steps (linear or super-linear)

## Test Plan

### Experiment Design
- **Task**: Varying step complexity (1, 2, 3, 4, 5 steps)
- **Models**: CG Standard vs CG-with-Residual-Correction vs Baseline
- **Data**: LIBERO-style synthetic data (400 train, 100 val)
- **Metric**: Loss improvement vs baseline at each step count

### Falsification Criteria
- REFUTED if: Residual correction helps single-step MORE than multi-step
- REFUTED if: Performance gap is constant across step counts
- SUPPORTED if: Residual correction disproportionately helps multi-step tasks
