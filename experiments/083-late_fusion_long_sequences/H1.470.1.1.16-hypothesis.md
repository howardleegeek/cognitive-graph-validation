# H1.470.1.1.16: Late-Fusion Scalability on Longer Sequences

## Hypothesis

Late-fusion architecture (separated encoders → independent temporal processing → late concatenation) scales better to longer sequences (20+ timesteps) than early fusion architectures. The independent temporal processing prevents cross-modal interference that accumulates over longer sequences.

## Concrete Prediction

If late-fusion scales better:
1. Performance gap between late-fusion and early-fusion should increase with sequence length
2. Late-fusion should maintain performance on long sequences while early-fusion degrades
3. Cognitive Graph should degrade most severely on long sequences due to unified representation interference

## Test Plan

### Experiment Design
- **Sequence lengths**: 5, 10, 20, 30, 40 timesteps
- **Architectures**: 
  - Baseline (no temporal)
  - LSTM-early (concat → LSTM)
  - LSTM-late (LSTM each → concat)
  - TempConv-early (concat → 1D conv)
  - TempConv-late (1D conv each → concat)
  - Cognitive Graph (unified → GNN)
- **Tasks**: Combined temporal + crossmodal
- **Data**: Synthetic LIBERO-style with varying sequence lengths
- **Metric**: Loss improvement vs baseline at each sequence length

### Falsification Criteria
- REFUTED if: Late-fusion degrades faster than early-fusion with sequence length
- REFUTED if: Performance gap remains constant or decreases with length
- SUPPORTED if: Late-fusion maintains performance while early-fusion degrades, gap increases
