# Round 202 Summary

**H1.436: CG Domain of Applicability** - Tested whether Cognitive Graph performs better on tasks with clear relational structure (object relationships) vs continuous control tasks (trajectory following). Results: **NOT SUPPORTED**. CG underperforms MLP on both task types, with relational tasks showing +254.1% worse performance and continuous control showing +41.5% worse. Interestingly, CG performs relatively better on continuous control than relational tasks - the opposite of the hypothesis. This consistent underperformance across multiple experiments (H1.434, H1.435, H1.436) suggests the simplified CG implementation may need significant refinement (larger capacity, different attention, proper graph structure) before it can demonstrate advantage over MLP baselines.
