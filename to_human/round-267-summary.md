# Round 267 Summary: Phase-Aware Training for Hierarchical Tasks

**Experiment H1.470.1.1.28** tested phase-aware training for hierarchical multi-step tasks, following the discovery that ensemble disagreement fails on structured tasks because it downweights phase transitions. The hypothesis was SUPPORTED with dramatic results: oracle phase labels achieved +99.82% average improvement across 3-5 phase tasks, and automatic phase detection from velocity changes achieved +99.05% improvement. This is a complete reversal from ensemble disagreement which degraded performance (-1.35% to -1.59%). The key principle discovered: **structured uncertainty (phase transitions) should be explicitly modeled, while random uncertainty (sensor noise) should be downweighted**. Phase-aware training works by encoding phase labels and transition information, providing strong learning signal for task structure. Next step: test phase-aware training on real robot data or develop hybrid approach combining phase-aware training with ensemble disagreement for mixed task types.
